# 강사용 진행안

## 수업 목표

참가자는 최신·직전 10-K의 MD&A를 이용해 다음을 수행한다.

1. 공시와 Item 7을 정확히 식별한다.
2. 추출 범위를 검증하고 오류 시 분석을 중단한다.
3. 전년 대비 경영진 설명의 변화를 분류한다.
4. 경영진의 인과관계 주장을 재무 숫자와 연결한다.
5. 투자·법무·회계 관점을 분리해 검토한다.
6. 원문 확인이 끝난 주장만 최종 메모에 사용한다.
7. 공시 후 최신 사건과 공식 거시지표를 서로 다른 evidence role로 통합한다.

## 권장 운영 방식

### 기존 60분 워크숍 안의 25분 모듈

| 시간 | 단계 | 강사 메시지 | 참가자 산출물 |
|---:|---|---|---|
| 33–36분 | 공시 선택 | 최신 문서만 보지 말고 비교 기준을 확보한다 | manifest |
| 36–40분 | MD&A 추출 | Item 7과 Item 7A는 다른 섹션이다 | current·prior MD&A |
| 40–43분 | Gate A | 추출 실패를 좋은 분석으로 보완할 수 없다 | extraction check |
| 43–48분 | 주장–숫자 연결 | “왜 변했나”를 숫자와 대조한다 | claim register |
| 48–52분 | Hybrid evidence | 최신 사건과 거시맥락의 역할을 구분한다 | external evidence |
| 52–58분 | 직군 검토 | 동일 근거를 서로 다른 질문으로 읽는다 | integrated register·memo |
| 58–60분 | Gate B | 중요한 세 주장만 원문에서 직접 확인한다 | 승인 표시 |

### 60분 독립 수업

| 시간 | 내용 |
|---:|---|
| 0–8분 | MD&A의 위치와 목적, Item 7·7A·8 구분 |
| 8–18분 | 환경 확인과 최신·직전 10-K 추출 |
| 18–25분 | 추출 경계 검증과 SEC 원문 열기 |
| 25–35분 | 전년 대비 서술 변화 분류 |
| 35–47분 | 주장–재무 숫자 연결 |
| 47–55분 | 투자·법무·회계 역할별 검토 |
| 55–60분 | Human Gate와 회고 |

## 수업 전 준비

1. 참가자에게 이 패키지를 미리 배포한다.
2. 강사는 수업과 동일한 네트워크에서 `AAPL` 또는 선택 종목을 한 번 실행한다.
3. `requirements.txt`의 버전을 유지한다.
4. SEC 접속이 차단된 회사 네트워크라면 미리 생성한 `mdna_current.md`, `mdna_prior.md`, manifest를 배포한다.
5. 실습 종목이 미국 국내 발행인의 10-K를 제출하는지 확인한다. 외국기업의 20-F는 별도 구조다.
6. 참가자를 투자·법무·회계 역할로 나누거나, 한 사람이 세 관점을 순서대로 수행하게 한다.
7. Tavily 호출은 핵심 트랙으로, FRED는 시간과 key가 있을 때만 선택 트랙으로 준비한다.

## Hybrid evidence 설명 도식

```text
MD&A claim
  ├─ SEC/EdgarTools: 회사가 실제로 말했는가? 숫자가 맞는가?
  ├─ Tavily: 공시 뒤 어떤 사건이 지지하거나 반박하는가?
  └─ FRED: 당시 금리·물가·고용 환경은 어땠는가?
                         ↓
              Integrated Evidence Register
                         ↓
                    Human Gate
```

FRED 추세와 회사 성과가 같이 움직이는 것은 인과관계의 증명이 아니다. Tavily 검색 결과도 원 출처를 열기 전에는 `unresolved`다.

## 추천 종목 선택 기준

- 최근 2년 모두 10-K가 있음
- 사업부문과 매출 동인이 비교적 분명함
- 유동성·Capex·마진 설명이 MD&A에 포함됨
- 지나치게 복잡한 금융회사나 합병 직후 회사는 첫 실습에서 피함

입문 예시: `AAPL`, `MSFT`, `NVDA`. 실제 수업 전 추출 상태를 반드시 확인한다.

## 강사용 핵심 설명

### 1. MD&A는 숫자의 사본이 아니다

재무제표가 “무엇이 변했는가”를 보여준다면 MD&A는 경영진이 “왜 변했다고 설명하는가”를 보여준다. 실습의 목표는 그 설명을 그대로 믿거나 요약하는 것이 아니라, 숫자와 다른 공시로 대조하는 것이다.

### 2. 세 가지 층을 분리한다

```text
회사 경영진의 주장
        ↓
공시·재무제표에서 확인되는 사실
        ↓
분석가 또는 Agent의 해석
```

### 3. 접수된 근거만 사용한다

`verified`는 “그럴듯함”이 아니라 원문 위치, 기간, 단위와 함께 확인됐다는 뜻이다. 시간이 부족하면 주장 수를 줄이고 검증 수준을 유지한다.

## Gate A — 추출 검증

다음 중 하나라도 해당하면 분석을 중단한다.

- MD&A가 비어 있거나 지나치게 짧음
- 실제 Item 7 제목이 없음
- 목차만 포함됨
- Item 7A 또는 Item 8 전체가 섞임
- 최신·직전 파일의 회사나 기간이 다름
- accession number와 SEC URL이 없음

## Gate B — 최종 검증

각 팀이 다음 세 표본을 SEC 원문에서 확인하게 한다.

1. 가장 중요한 성장 또는 마진 주장
2. 유동성·Capex·차입 관련 주장
3. `partial`, `needs_source` 또는 `conflict` 중 하나

## 직군별 질문

### 투자

- 가격·판매량·제품 구성·환율 중 무엇이 성장의 원인인가?
- 매출 성장과 마진·현금흐름이 같은 방향인가?
- Capex 증가가 미래 성장인지 유지비용인지 구분되는가?
- 경영진의 강조와 실제 숫자가 일치하는가?

### 회계

- 중요한 회계 추정이나 판단이 바뀌었는가?
- 일회성·비GAAP 조정이 반복되는가?
- 운전자본이 영업현금흐름을 왜곡하는가?
- 손상·충당금·매출 인식과 관련된 불확실성이 있는가?

### 법무

- 과거 사실과 미래예측 진술이 구분되는가?
- 불확실성을 완화하거나 강화한 표현이 있는가?
- Item 1A Risk Factors와 MD&A 설명이 일관되는가?
- 규제·소송·계약상 의무가 유동성 설명에 반영되는가?

## 마무리 질문

- Agent가 가장 자신 있게 말했지만 근거가 약했던 주장은 무엇인가?
- 전년 대비 삭제된 설명 중 가장 중요한 것은 무엇인가?
- 재무 숫자만 봤다면 놓쳤을 경영진 설명은 무엇인가?
- 다음 분석에서 자동화할 단계와 사람이 유지할 단계는 무엇인가?
