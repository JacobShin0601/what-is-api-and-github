# MD&A Review — 형식 예시

## 1. 경영진이 가장 강조한 변화

- 매출 변화의 원인 설명이 전년보다 구체화됐다. `[MDA-001 · partial]`

## 2. 실제 숫자로 확인된 주장

- 이 예시 패키지에는 실제 회사 숫자를 포함하지 않는다.

## 3. 부분적으로만 확인된 주장

- 가격·판매량 효과의 방향은 언급됐지만 각각의 기여도는 확인되지 않았다. `[MDA-001 · partial]`

## 4. 전년 대비 새로 등장한 우려

- 실제 실습에서 current·prior 근거를 연결한다.

## 5. 추가 원문 검토가 필요한 항목

- 재무제표와 MD&A의 기간·단위를 확인한다. `[MDA-001 · needs_source]`
